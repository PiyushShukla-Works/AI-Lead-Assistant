# AI Lead Assistant

AI Lead Assistant is a chatbot for small businesses. It answers customer questions, explains business details, and helps collect leads.

## Features

- Chat UI like a modern AI assistant
- FastAPI backend
- Local LLM support using Ollama
- Business information prompt
- User signup/login planned
- Lead capture planned

## Tech Stack

- HTML
- CSS
- JavaScript
- FastAPI
- Python
- Ollama
- MySQL

## Status

Currently building MVP.
